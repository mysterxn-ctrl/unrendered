# Code of conduct

Unrendered adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussions about the work. Harassment, discrimination, personal attacks and publishing others' private information are not tolerated in any project space — issues, pull requests, discussions or community channels.

## Reporting

Report unacceptable behaviour privately to the maintainer, Ruben Ferraro, through GitHub's private vulnerability reporting (**Security → Report a vulnerability**) and mark the report as a conduct issue, or contact Ruben Ferraro through the GitHub profile linked from this repository. All reports are reviewed promptly and handled confidentially. The maintainer may remove, edit or reject contributions and temporarily or permanently ban contributors who violate this code of conduct.
